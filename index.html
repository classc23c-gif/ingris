Kamera Tidak Dapat Diakses

Izin kamera ditolak atau perangkat tidak memiliki kamera. Jangan khawatir, kamu tetap bisa bermain menggunakan Mouse atau Layar Sentuh!

💡 Cara Mengaktifkan Kamera di Browser:

1. Klik ikon Gembok (🔒) atau Kamera (📷) di sebelah kiri alamat website (URL bar) di bagian atas browser.

2. Ubah izin Camera / Kamera menjadi Allow / Izinkan.

3. Pastikan website dibuka melalui localhost atau HTTPS, lalu klik tombol Coba Kamera Lagi.

📖 Panduan Bermain & Petunjuk Teknis

🎮 Cara Bermain

  • Baca pertanyaan pilihan ganda di bagian atas layar.
  • Empat gelembung jawaban (A, B, C, D) akan melayang secara acak di layar.
  • Mode Kamera: Angkat satu tanganmu di depan kamera. Kursor tangan (✋) di layar akan mengikuti gerakan tanganmu. Arahkan dan tahan sebentar (~0,35 detik) pada gelembung jawaban untuk menangkapnya.
  • Mode Mouse / Layar Sentuh (Smart Board): Klik atau sentuh langsung gelembung jawaban yang dipilih, atau arahkan kursor ke gelembung tersebut.
  • Jawaban Benar mendapat +10 poin dan otomatis lanjut ke soal berikutnya. Jawaban Salah akan memunculkan pesan "Coba lagi!".

💻 Cara Menjalankan Website (Localhost / HTTPS)

Demi keamanan privasi browser modern, fitur Kamera (WebRTC / MediaPipe) hanya diizinkan berjalan pada protokol HTTPS atau http://localhost. Pilih salah satu cara mudah berikut:

  1. VS Code Live Server: Simpan file ini sebagai index.html, klik kanan di VS Code, lalu pilih "Open with Live Server" (otomatis membuka http://127.0.0.1:5500).
  2. Python Local Server: Buka terminal di folder file ini lalu jalankan python -m http.server 8000, kemudian buka http://localhost:8000 di Chrome/Edge.
  3. Hosting HTTPS Gratis: Unggah file index.html ke GitHub Pages, Netlify Drop, atau Vercel agar bisa diakses dari Laptop, Tablet, dan Smart Board sekolah secara langsung.
